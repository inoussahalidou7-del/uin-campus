# UIN-Campus

Systeme de gestion academique de l'UIN.

##  Environnement de developpement (Partie A)
Voici les versions des outils utilises pour ce projet :
- **g++** : 14.x.x (14.2.0)
- **clang++** : 18.x.x (18.1.3)
- **cmake** : 3.28.x (3.28.3)
- **ninja** : 1.11.x (1.11.1)
- **gdb** : 14.x (15.1)
- **git** : 2.43.x (2.43.0)

##  Compilation et Execution
Pour compiler le projet avec le preset debug :
```bash
cmake --preset debug
cmake --build --preset debug
